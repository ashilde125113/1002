# 日常簿｜每日待辦行事曆

以繁體中文製作的響應式個人行事曆待辦網站。可直接選取年月日、瀏覽月曆，並為每天建立多個待辦事項，分別管理分類、完成狀態、編輯與刪除。

## 在自己的電腦預覽

直接用瀏覽器開啟 `index.html` 即可。為了讓正式網站的儲存與分享功能最穩定，請以 HTTPS 網址部署網站。

## 部署到 Netlify（免費靜態網站）

1. 前往 [Netlify Drop](https://app.netlify.com/drop)，以電子郵件或 GitHub 登入 Netlify。
2. 將包含 `index.html`、`README.md`、`netlify.toml` 和 `_headers` 的**專案資料夾**拖入頁面。
3. 等候 Netlify 完成發布，複製頁面提供的 `https://...netlify.app` 網址並分享給其他人。
4. 如果之後修改網站，再把更新過的專案資料夾拖入同一個 Netlify 網站部署。

亦可將這些檔案放進 GitHub 儲存庫，並透過 Vercel、Netlify 或 GitHub Pages 部署。

## 隱私與同步限制

- 網站開放所有訪客使用，但每個人的待辦事項都獨立儲存在**自己的瀏覽器**，不會公開或混入其他人的資料。
- 資料以網站網址為單位儲存在瀏覽器 `localStorage`；同一個網站網址、同一瀏覽器下次開啟時，可繼續使用個人行事曆。
- 待辦事項不會同步到不同裝置或瀏覽器。清除瀏覽器網站資料、更換瀏覽器或使用另一台裝置後，原有資料不會跟著移轉。
- 此版本不使用帳號、伺服器或雲端資料庫。若要跨裝置同步或多人共同管理同一本行事曆，需要額外建置帳號登入與雲端資料庫。

## 技術與限制

此專案為無需建置步驟的靜態網站，使用原生 HTML、CSS、JavaScript 和瀏覽器 `localStorage`，不依賴安裝套件。除載入網頁字型以外，網站功能由瀏覽器本機執行。
